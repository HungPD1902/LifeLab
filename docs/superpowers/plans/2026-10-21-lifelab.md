# LifeLab Wireframe Implementation Plan

> Thực hiện trực tiếp trong phiên này; người dùng yêu cầu tạo project trong thư mục DoAn2026 hiện tại. Dự án mới chưa có commit, không cần worktree khác.

**Goal:** Expo app giao diện tĩnh có thể điều hướng qua toàn bộ các màn wireframe LifeLab.

**Architecture:** Expo Router cung cấp bốn route tab và các route chi tiết. Bộ UI dùng chung giữ màu sắc/khoảng cách nhất quán; module màn hình theo từng nhóm và dữ liệu mẫu tách riêng. Registry ánh xạ node Figma sang route để kiểm tra độ bao phủ.

**Tech Stack:** Expo, TypeScript, React Native, Expo Router.

**Spec:** ../specs/2026-10-21-lifelab-design.md

## Global Constraints

- Giữ Figma chỉ đọc; tạo code tại thư mục hiện tại.
- Tiếng Việt, trắng/xám/đen, dữ liệu tĩnh trong bộ nhớ.
- Không backend, không lưu mật khẩu, không gửi yêu cầu bên ngoài trong app.

## Review Focus

- Back từ route mở trực tiếp có đường trở về tab phù hợp.
- Safe area và bàn phím không che nút, nội dung cuộn được trên màn nhỏ.
- Bộ lọc và từng nút chính có phản hồi/đích đến.
- Empty state, dialog hủy, đăng xuất có thể quay lại đúng luồng.
- Các trạng thái tạo lớp/tham gia lớp được phân biệt; không phát sinh dữ liệu thật.

## Tasks

- [x] 1. Khởi tạo Expo TypeScript; cài Router, safe area, icons và web; thêm cấu hình app, bộ UI và dữ liệu mẫu.
- [x] 2. Triển khai On boarding/Auth/Home/Skill theo metadata, ảnh tham chiếu, điều hướng và tương tác bộ lọc/bài học.
- [x] 3. Triển khai Class/Profile cùng các dialog, empty state và biểu mẫu tĩnh; ghi danh mục route với node Figma.
- [x] 4. Kiểm tra TypeScript, Expo dependencies, bundle web và native; chạy kiểm tra trình duyệt cho các luồng chính và route inventory; viết README hướng dẫn chạy và giới hạn.

Verification: `npm run typecheck`, `npx expo install --check`, `npm run export:web`, `npm run test:e2e`; native bundle Android/iOS bằng `expo export --platform all`. UI tĩnh được kiểm tra qua browser interaction thay vì viết unit test sao chép implementation.
